# Ohmyfood

Ohmyfood est un site vitrine de restaurants haut de gamme. Le projet met l'accent sur l'integration HTML/CSS, la mise en page responsive et les animations CSS.

## Apercu

- Page d'accueil avec sections fonctionnement et restaurants.
- Pages de menus individuelles par restaurant.
- Animations CSS (loader, effets d'apparition, like).
- Design responsive.

## Contenu

- Liste de restaurants avec badges "Nouveau".
- Pages menus avec cartes d'entrees, plats et desserts.
- Interactions visuelles et transitions.

## Stack technique

- HTML5
- CSS3

## Lancer le projet

Ouvrir `index.html` dans un navigateur.
